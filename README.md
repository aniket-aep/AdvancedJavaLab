# Student Registration Form

A simple Java Swing application created as part of the Advanced Java Lab.

## Features

- Enter student details
- Select gender using radio buttons
- Reset form fields
- Submit button with basic validation

## Technologies Used

- Java
- Swing
- AWT Event Handling

## How to Run

1. Open the project in your Java IDE.
2. Compile the source file.
3. Run the main class.

## Purpose

This project was developed to understand Java Swing components, event handling, and GUI design.
